LenDenClub · console tool

Portfolio scraper

One file. Pulls your open and closed loans, joins borrower details, and writes the two JSON exports that scripts/build-data.mjs expects. Everything stays in your browser.

Download scraper.js Back to dashboard

Run it

  1. Open app.lendenclub.com and sign in.
  2. Open DevTools (F12) → Console.
  3. Paste the entire contents of lendenclub-scraper.js and press Enter.
  4. Wait for DONE. Two files download: lending_data_import_YYYY-MM-DD.json and lendenclub_FULL_YYYY-MM-DD.json.
  5. Move both into data/raw/, then run:
npm run data:build
npm run build

If credential detection fails

Open DevTools → Network, click any investor-api.lendenclub.com request, and copy:

  • investor_id from the query string, into CONFIG.investorId.
  • x-ldc-key from the request headers, into CONFIG.apiKey.

Privacy

Raw exports contain borrower names, cities and signed agreement URLs. They are gitignored on purpose. Only the sanitised, derived dataset in public/data/ is published.

The scraper removes agreement links and PAN / phone / email fields by default. Set stripAgreement: false only if you need the links locally.
